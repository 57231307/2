## 三、开发规范

### 3.1 代码规范
- TypeScript严格模式
- 命名规范：PascalCase（类）、camelCase（变量）、UPPER_SNAKE_CASE（常量）
- 每个模块包含：entity、service、controller、dto、module

### 3.2 Git规范
- 分支命名：feature/xxx, bugfix/xxx
- 提交信息：feat: 新功能、fix: 修复、docs: 文档

### 3.3 API规范
- RESTful风格
- URL格式：/api/v1/{resource}
- 响应格式：{success, data, message}
