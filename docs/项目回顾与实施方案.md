## 一、项目规划总览

### 1.1 项目背景

**项目名称**：纺织面料ERP系统（Fabric ERP System）

**行业定位**：面向针织面料行业的企业级资源计划系统

**核心特性**：
- 颜色管理（颜色配方、色差控制）
- 花型管理（花型设计、版权保护）
- 多单位换算（米、公斤、码等）
- 严格批次跟踪（缸号、匹号）
- 质检流程复杂
- 财务成本精确核算

### 1.2 系统目标

| 目标类型 | 具体指标 |
|---------|---------|
| **高准确性** | 确保所有业务数据的准确性和一致性 |
| **高性能** | 系统响应时间 <200ms，支持 >100万条数据 |
| **数据唯一性** | 通过严格的数据校验和唯一约束确保数据不重复 |
| **全流程覆盖** | 覆盖企业运营的各个环节 |

- **扩展性**：支持水平扩展

### 5.3 数据库设计原则

#### 核心表结构

1. **产品颜色变体表**（`product_color_variants`）
   - `color_no` - 色号（唯一）
   - `lab_l`, `lab_a`, `lab_b` - LAB值
   - `sale_price` - 独立价格

2. **批次表**（`inventory_batches`）
   - `batch_no` - 缸号
   - `roll_no` - 匹号
   - 唯一约束：`uk_batch_roll`（batch_no + roll_no）

3. **颜色配方表**（`color_formulas`）
   - 染料名称、用量
   - LAB值对比
   - ΔE色差计算

4. **花型表**（`patterns`）
   - 花型图片
   - 版权信息
   - 授权范围
