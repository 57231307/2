# 面料报价微信小程序 - 设计文档

## 1. 项目概述

**项目名称**：面料报价  
**项目目标**：为布行内部员工提供便捷的面料管理和报价生成工具  
**目标用户**：布行内部员工  
**使用场景**：店内接待客户、外出见客户、办公室日常管理

## 2. 系统架构

```
┌─────────────────────────┐
│   微信小程序（前端）    │
│   - 面料管理页面       │
│   - 报价生成页面       │
│   - 统计分析页面       │
└───────────┬─────────────┘
            │ HTTPS
            ▼
┌─────────────────────────┐
│  Node.js后端服务        │
│  - API接口层            │
│  - 业务逻辑层           │
│  - 数据访问层           │
└───────────┬─────────────┘
            │
            ▼
┌─────────────────────────┐
│  SQLite 数据库文件      │
│  - fabric.db           │
└─────────────────────────┘
```

## 3. 功能模块详细设计

### 3.1 模块一：面料管理

#### 3.1.1 面料列表
- 展示所有面料信息
- 支持按类型、编号搜索筛选
- 支持分页加载

#### 3.1.2 面料详情
- 展示完整面料信息（包括所有价格字段）
- 支持编辑面料信息

#### 3.1.3 面料导入
- 支持Excel批量导入
- 完全兼容现有报价表格式
- 支持数据验证和错误提示

#### 3.1.4 面料编辑
- 修改面料基本信息
- 修改面料价格信息
- 保存变更历史

#### 3.1.5 面料分类
- 按类型管理面料
- 支持类型的增删改

### 3.2 模块二：报价生成

#### 3.2.1 新建报价单
- 输入客户名称（可选）
- 添加面料到报价单
- 输入面料数量
- 选择计价单位（米/公斤）

#### 3.2.2 智能计算
- 根据面料价格、数量自动计算
- 支持加价选项（如撞白、高牢度+3元等）
- 支持折扣调整
- 自动计算小计和总价

#### 3.2.3 价格调整
- 手动调整单价
- 批量调整折扣
- 添加备注说明

#### 3.2.4 报价单预览
- 生成美观的报价单格式
- 显示面料明细、价格、总价
- 支持预览和修改

#### 3.2.5 报价单分享
- 生成图片格式的报价单
- 通过微信转发给客户
- 保存报价单历史记录

### 3.3 模块三：统计分析

#### 3.3.1 报价统计
- 按时间统计报价数量和金额
- 按面料统计报价次数
- 图表展示统计数据

#### 3.3.2 销售排行
- 面料销售排行榜
- 支持按时间范围筛选

#### 3.3.3 数据导出
- 支持导出Excel报表
- 支持导出报价单历史

## 5. 技术实现方案

### 5.1 前端技术栈

- 微信小程序原生框架
- WXML + WXSS + JavaScript
- 微信API（分享、存储等）

### 5.2 后端技术栈

- Node.js + Express
- SQLite 数据库
- Sequelize ORM
- JWT 身份认证
- Multer（Excel文件上传）
- xlsx（Excel文件解析）

## 6. 数据导入功能

完全兼容现有报价表格式，支持一键导入：
- 支持"内部销售报价表（新）"格式
- 支持"内部销售报价表（旧）"格式
- 自动识别字段并映射
- 数据验证和错误提示
- 导入进度显示

## 7. 部署方案

### 7.1 服务器要求

- 操作系统：Linux/Windows
- Node.js：v14+
- 内存：2GB+
- 硬盘：10GB+

### 7.2 部署步骤

1. 安装Node.js环境
2. 克隆项目代码
3. 安装依赖：`npm install`
4. 配置环境变量
5. 启动服务：`npm start`
6. 配置微信小程序服务器域名
7. 发布小程序
