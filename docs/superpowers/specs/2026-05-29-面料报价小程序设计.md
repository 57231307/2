# 面料报价微信小程序 - 轻量化设计文档

## 1. 项目概述

**项目名称**：面料报价  
**项目目标**：为布行内部员工提供极简的面料管理和报价生成工具  
**目标用户**：布行内部员工  
**使用场景**：店内接待客户、外出见客户、办公室日常管理  
**设计原则**：极简、轻量、易用

## 2. 系统架构

采用微信云开发，无需自建服务器：

```
┌─────────────────────────┐
│   微信小程序（前端）    │
│   - 面料列表页面       │
│   - 报价生成页面       │
│   - 报价历史页面       │
└───────────┬─────────────┘
            │ 微信云开发API
            ▼
┌─────────────────────────┐
│  微信云开发             │
│  - 云数据库             │
│  - 云存储               │
│  - 云函数               │
└─────────────────────────┘
```

## 3. 功能模块详细设计（轻量化）

### 3.1 模块一：面料管理

#### 3.1.1 面料列表
- 展示所有面料信息
- 支持按类型、编号搜索筛选

#### 3.1.2 面料详情
- 展示完整面料信息（包括所有价格字段）
- 支持编辑面料信息

#### 3.1.3 面料导入
- 支持Excel批量导入
- 完全兼容现有报价表格式

### 3.2 模块二：报价生成

#### 3.2.1 新建报价单
- 输入客户名称（可选）
- 添加面料到报价单
- 输入面料数量
- 选择计价单位（米/公斤）

#### 3.2.2 智能计算
- 根据面料价格、数量自动计算
- 支持加价选项（如撞白、高牢度+3元等）
- 自动计算小计和总价

#### 3.2.3 报价单预览和分享
- 生成简洁的报价单格式
- 通过微信转发给客户
- 保存报价单历史记录

### 3.3 模块三：报价历史

- 查看历史报价单
- 支持搜索和筛选
- 重新分享历史报价

## 5. 技术实现方案（轻量化）

### 5.1 前端技术栈

- 微信小程序原生框架
- WXML + WXSS + JavaScript
- 微信云开发SDK

### 5.2 云开发

- 微信云数据库
- 微信云存储（用于Excel文件）
- 微信云函数（用于Excel解析）

## 6. 数据导入功能

完全兼容现有报价表格式，支持一键导入：
- 支持"内部销售报价表（新）"格式
- 支持"内部销售报价表（旧）"格式
- 自动识别字段并映射

## 7. 部署方案（极简）

### 7.1 开通微信云开发

1. 注册微信小程序
2. 在开发者工具中开通云开发
3. 创建云环境

### 7.2 发布步骤

1. 在开发者工具中打开项目
2. 上传云函数
3. 创建数据库集合
4. 上传小程序代码
5. 提交审核发布
