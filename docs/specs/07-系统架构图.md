## 二、技术架构详细说明

### 2.1 分层架构说明

| 层次 | 技术选型 | 职责 |
|------|----------|------|
| 前端层 | Angular 22 + Tailwind CSS | 用户界面展示、交互逻辑 |
| 网关层 | Nginx | 负载均衡、静态资源、API路由 |
| 应用层 | NestJS 10 + TypeScript | 业务逻辑、API服务 |
| 数据层 | PostgreSQL 15 + Redis 7 | 数据存储、缓存加速 |
| 基础设施 | Docker + Docker Compose | 部署与容器编排 |
