## 1. 销售订单流程

### 1.1 标准销售订单流程

```mermaid
flowchart TD
    A[客户需求] --> B[创建销售订单]
    B --> C[订单审批]
    C --> D{审批通过?}
    D -->|是| E[确认订单]
    D -->|否| F[返回修改]
    E --> G[排产/分配库存]
    G --> H[安排生产]
    H --> I[生产完成]
    I --> J[库存发货]
    J --> K[物流发货]
    K --> L[订单完成]
```

### 1.2 销售订单详细流程

| 步骤 | 操作 | 说明 | 责任方 |
|------|------|--------|
| 1 | 客户下单 | 客户通过线上或线下方式下单 | 客户/销售员 |
| 2 | 创建订单 | 在系统中创建销售订单，选择产品、颜色、数量 | 销售员 |
| 3 | 订单审批 | 根据金额大订单需要审批 | 销售主管 |
| 4 | 确认订单 | 确认订单信息，锁定库存 | 销售员 |
| 5 | 生产计划 | 根据订单安排生产计划 | 生产计划员 |
| 6 | 生产执行 | 安排生产任务，进行生产 | 生产车间 |
| 7 | 质量检验 | 生产完成后进行检验 | 质检员 |
| 8 | 安排发货 | 检验通过后安排发货 | 仓库管理员 |
| 9 | 物流发货 | 联系物流公司发货 | 物流专员 |
| 10 | 订单完成 | 客户收货确认 | 销售员 |

## 2. 采购流程

### 2.1 标准采购流程

```mermaid
flowchart TD
    A[采购需求] --> B[创建采购申请]
    B --> C[采购审批]
    C --> D{审批通过?}
    D -->|是| E[供应商询价]
    D -->|否| F[重新申请]
    E --> G[确定供应商]
    G --> H[创建采购订单]
    H --> I[供应商发货]
    I --> J[到货检验]
    J --> K{检验通过?}
    K -->|是| L[入库]
    K -->|否| M[退货/退换货]
    L --> N[采购完成]
```

## 3. 库存管理流程

### 3.1 入库流程

```mermaid
flowchart TD
    A[到货通知] --> B[准备入库]
    B --> C[质量检验]
    C --> D{检验合格?}
    D -->|是| E[分配库位]
    D -->|否| F[拒收/处理]
    E --> G[入库上架]
    G --> H[库存增加]
    H --> I[更新库存]
```

### 3.2 出库流程

```mermaid
flowchart TD
    A[订单发货] --> B[生成拣货单]
    B --> C[拣货]
    C --> D[出库检验]
    D --> E[出库确认]
    E --> F[发货]
    F --> G[库存减少]
    G --> H[更新库存]
```

### 3.3 盘点流程

```mermaid
flowchart TD
    A[创建盘点任务] --> B[开始盘点]
    B --> C[录入盘点数据]
    C --> D[差异分析]
    D --> E[差异审批]
    E --> F[调整库存]
    F --> G[盘点完成]
```

## 4. 生产管理流程

### 4.1 生产工单流程

```mermaid
flowchart TD
    A[生产计划] --> B[创建生产工单]
    B --> C[工单审核]
    C --> D[安排生产]
    D --> E[领料生产]
    E --> F[生产报工]
    F --> G[质量检验]
    G --> H{检验合格?}
    H -->|是| I[成品入库]
    H -->|否| J[返工/报废]
    I --> K[工单完成]
```
