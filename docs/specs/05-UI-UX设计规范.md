# 纺织面料ERP系统 - UI/UX设计规范

> 版本：V1.0
> 日期：2026年6月7日

---

## 一、设计理念

### 1.1 设计原则

- **简洁高效**：减少操作步骤，提高工作效率
- **专业可靠**：企业级应用风格，稳重专业
- **直观易用**：符合用户习惯，降低学习成本
- **一致统一**：保持交互和视觉一致性

### 1.2 目标用户

| 用户角色 | 主要职责 | 操作特点 |
|----------|----------|----------|
| 业务员 | 销售报价/订单 | 高频操作、快速流转 |
| 采购员 | 采购管理 | 批量操作、流程跟踪 |
| 仓管员 | 库存管理 | 精确操作、批次管理 |
| 质检员 | 质量检验 | 数据记录、报告生成 |
| 财务人员 | 财务核算 | 数据准确、报表统计 |
| 管理人员 | 数据分析 | 全局视图、决策支持 |
| 系统管理员 | 系统维护 | 配置管理、权限控制 |

## 三、组件规范

#### 3.1.1 按钮类型

| 类型 | 样式 | 场景 |

| 文字按钮 | 仅文字 | 编辑、删除等 |
| 图标按钮 | 仅图标 | 工具栏快捷操作 |

#### 3.1.2 按钮尺寸

| 尺寸 | 高度 | 内边距 | 字体大小 |
|------|------|--------|----------|
| 大 | 40px | 16px 24px | 16px |

| 小 | 24px | 8px 12px | 12px |

### 3.2 表单规范

## 六、交互规范

### 6.1 通用交互

#### 6.1.1 加载状态

| 场景 | 加载方式 |
|------|----------|
| 页面初次加载 | 全屏Loading |
| 表格数据加载 | 表格内Loading |
| 按钮操作后 | 按钮Loading |

#### 6.1.2 确认操作

- 删除操作：弹出确认对话框
- 重要操作（如审批）：二次确认
- 可撤销操作：提供撤销提示

#### 6.1.3 成功提示

- 操作成功后显示Toast提示
- 显示时长：2-3秒
- 颜色：绿色

#### 6.1.4 错误提示

- 表单校验错误：字段下方显示红色提示
- 业务错误：弹出错误对话框
- 系统错误：显示错误代码和联系支持

### 6.2 表格交互

#### 6.2.1 排序

- 可排序列标题显示排序图标
- 点击切换升/降序
- 默认无排序

#### 6.2.2 筛选

- 表头点击显示筛选菜单
- 支持多条件筛选
- 筛选结果显示筛选标签

#### 6.2.3 列设置

- 用户可自定义显示列
- 配置持久化保存

## 七、响应式设计

### 7.1 适配断点

| 设备 | 宽度范围 | 布局模式 |
|------|----------|----------|
| 桌面端 | ≥1280px | 完整布局 |
| 平板 | 768-1279px | Sidebar可收起 |
| 移动端 | <768px | 简化布局（可选）|

### 7.2 适配策略

- 优先保证桌面端体验
- 移动端可选使用独立App
- 基础功能在平板端可用

## 八、无障碍设计

### 8.1 键盘操作

- 所有功能可通过键盘完成
- Tab顺序合理
- 焦点可见

### 8.2 对比度

- 文字与背景对比度 ≥4.5:1
- 大文字对比度 ≥3:1

### 8.3 屏幕阅读器

- 图片有alt文本
- 表单有label
- 按钮有描述
