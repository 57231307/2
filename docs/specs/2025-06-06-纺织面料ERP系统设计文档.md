## 1. 项目概述

### 1.1 项目背景

本项目为纺织面料行业打造的全功能企业级ERP系统，覆盖从研发、生产、销售、库存、财务、服务到数字化转型的全链条管理。

### 1.2 核心需求

- **高准确性：** 数据唯一性约束、数据校验、审计追溯
- **高性能：** 支持100万+数据量、响应时间 <200ms
- **数据唯一性：** 业务主键、颜色配方、批次号、花型版本等唯一管理
- **面料行业特性：** 颜色管理、花型版权、多单位换算、染整配方

### 1.3 技术选型

| 层级 | 技术栈 | 版本 |
|------|--------|------|
| 前端 | Angular | 22+ |
| 前端表单 | SignalForms | 最新版 |
| 前端变更检测 | OnPush | 默认开启 |
| 后端 | NestJS | 10+ |
| 数据库 | PostgreSQL | 16+ |
| 缓存/消息队列 | Redis | 7+ |

## 4. 数据库设计

| id | UUID | 主键 | PRIMARY KEY |
| product_no | VARCHAR(50) | 产品编码 | UNIQUE NOT NULL |
| name | VARCHAR(200) | 产品名称 | NOT NULL |
| category | VARCHAR(100) | 产品分类 | |
| composition | VARCHAR(200) | 成分 | |
| weight | NUMERIC(10,2) | 克重 (g/m²) | |
| width | NUMERIC(10,2) | 幅宽 (cm) | |
| unit | VARCHAR(20) | 单位 | |
| created_at | TIMESTAMPTZ | 创建时间 | |
| updated_at | TIMESTAMPTZ | 更新时间 | |

#### 颜色配方表 (color_formulas)

| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| id | UUID | 主键 | PRIMARY KEY |
| product_id | UUID | 产品ID | REFERENCES products(id) |
| color_code | VARCHAR(50) | 色号 | NOT NULL |
| color_name | VARCHAR(100) | 色名 | |
| lab_l | NUMERIC(5,2) | Lab值 L | |
| lab_a | NUMERIC(5,2) | Lab值 a | |
| lab_b | NUMERIC(5,2) | Lab值 b | |
| version | INT | 版本号 | DEFAULT 1 |
| status | VARCHAR(20) | 状态 | |

| name | VARCHAR(200) | 花型名称 | |
| designer_id | UUID | 设计师ID | |
| copyright_owner | VARCHAR(200) | 版权所有人 | |
| created_at | TIMESTAMPTZ | | |

#### 花型版本表 (pattern_versions)

| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| id | UUID | 主键 | PRIMARY KEY |
| pattern_id | UUID | 花型ID | REFERENCES patterns(id) |
| version_no | VARCHAR(20) | 版本号 | |

| thumbnail | VARCHAR(500) | 缩略图 | |
| approval_date | TIMESTAMPTZ | 审批日期 | |
| status | VARCHAR(20) | 状态 | |

**唯一约束：** `UNIQUE (pattern_id, version_no)`

#### 批次表 (batches)

| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| id | UUID | 主键 | PRIMARY KEY |
| batch_no | VARCHAR(50) | 批次号 | UNIQUE NOT NULL |
| factory_id | UUID | 工厂ID | |
| batch_type | VARCHAR(20) | 批次类型 | |
| color_formula_id | UUID | 颜色配方ID | |
| lab_l | NUMERIC(5,2) | 实际Lab值 L | |
| lab_a | NUMERIC(5,2) | 实际Lab值 a | |
| lab_b | NUMERIC(5,2) | 实际Lab值 b | |
| delta_e | NUMERIC(5,2) | ΔE色差 | |
| quantity | NUMERIC(15,2) | 数量 | |
| unit | VARCHAR(20) | 单位 | |
| produced_date | TIMESTAMPTZ | 生产日期 | |

**唯一约束：** `UNIQUE (factory_id, batch_type, batch_no)`

### 4.2 分区表策略

```sql
-- 销售订单按月份分区
CREATE TABLE sales_orders (
    id UUID PRIMARY KEY,
    order_no VARCHAR(20) NOT NULL,
    customer_id UUID NOT NULL,
    created_at TIMESTAMPTZ NOT NULL,
    -- 其他字段...
) PARTITION BY RANGE (created_at);

-- 创建分区
CREATE TABLE sales_orders_2025_01 PARTITION OF sales_orders
    FOR VALUES FROM ('2025-01-01') TO ('2025-02-01');

CREATE TABLE sales_orders_2025_02 PARTITION OF sales_orders
    FOR VALUES FROM ('2025-02-01') TO ('2025-03-01');
-- 继续创建其他月份分区
```

## 5. API设计

### 5.1 API规范

- 协议：HTTPS
- 数据格式：JSON
- 认证：JWT Bearer Token
- 版本控制：URL路径 `/api/v1/...`

### 5.2 标准响应格式

```json
{
  "success": true,
  "data": {},
  "message": "操作成功",
  "timestamp": "2025-06-06T10:00:00Z"
}
```

### 5.3 核心API示例

#### 产品API

```
GET    /api/v1/products              # 获取产品列表
GET    /api/v1/products/:id          # 获取产品详情
POST   /api/v1/products              # 创建产品
PUT    /api/v1/products/:id          # 更新产品
DELETE /api/v1/products/:id          # 删除产品
```

#### 颜色配方API

```
GET    /api/v1/products/:id/color-formulas    # 获取产品颜色配方列表

GET    /api/v1/color-formulas/:id             # 获取颜色配方详情
PUT    /api/v1/color-formulas/:id             # 更新颜色配方
```

## 6. 事件驱动设计

### 6.1 领域事件示例

```typescript
// 领域事件基类
abstract class DomainEvent {
  readonly id: string;
  readonly occurredAt: Date;
  readonly aggregateId: string;
}

// 订单创建事件
class OrderCreatedEvent extends DomainEvent {
  readonly orderNo: string;
  readonly customerId: string;
  readonly items: OrderItem[];
}

// 库存变更事件
class InventoryChangedEvent extends DomainEvent {
  readonly productId: string;
  readonly batchId: string;
  readonly delta: number;
  readonly type: 'IN' | 'OUT';
}

// 颜色配方审批通过事件
class ColorFormulaApprovedEvent extends DomainEvent {
  readonly formulaId: string;
  readonly productId: string;
  readonly colorCode: string;
}
```

### 6.2 事件处理流程

```
[业务操作] → [领域事件触发] → [Event Bus] → [事件处理器] → [更新状态/发送通知]
```
