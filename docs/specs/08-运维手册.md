## 二、快速部署指南

### 2.1 开发环境快速部署

#### 2.1.1 前提准备

```bash
# 检查Docker和Docker Compose安装
docker --version
docker-compose --version

# 克隆项目代码
git clone <repository-url>
cd /workspace
```

#### 2.1.2 启动基础设施

```bash
cd infra/docker

# 复制环境变量配置文件
cp .env.example .env

# 编辑配置文件
vim .env

# 启动服务
docker-compose up -d
```

#### 2.1.3 验证部署

```bash
# 检查容器状态
docker-compose ps

# 查看日志
docker-compose logs -f

# 访问应用
# - 前端: http://localhost:8080
# - 后端API: http://localhost:3000
# - API文档: http://localhost:3000/api/docs
```

### 2.2 生产环境部署

#### 2.2.1 生产环境配置

```bash
# 在生产服务器上执行

# 1. 安全配置（修改密码）

# - POSTGRES_PASSWORD=生产数据库密码
# - REDIS_PASSWORD=生产Redis密码
# - JWT_SECRET=强密钥
```

```bash
# 检查服务健康状态
curl http://localhost:3000/api/health

# 检查数据库连接
docker-compose exec postgres psql -U postgres -d fabric_erp -c "SELECT 1"
```

## 四、备份与恢复

### 4.1 数据库备份

#### 4.1.1 自动备份（推荐）

```bash
# 创建备份脚本
vim /usr/local/bin/backup_db.sh
```

```bash
#!/bin/bash
# 数据库备份脚本

DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR="/backup/postgres"
DOCKER_CONTAINER="infra-docker-postgres-1"

# 创建备份目录
mkdir -p $BACKUP_DIR

# 执行备份
docker exec $DOCKER_CONTAINER pg_dump -U postgres fabric_erp | gzip > $BACKUP_DIR/fabric_erp_$DATE.sql.gz

# 保留最近7天的备份
find $BACKUP_DIR -name "fabric_erp_*.sql.gz" -mtime +7 -delete
```

```bash
# 添加执行权限
chmod +x /usr/local/bin/backup_db.sh

# 添加定时任务（每天凌晨2点执行）
crontab -e
0 2 * * * /usr/local/bin/backup_db.sh
```

#### 4.1.2 手动备份

```bash
# 手动执行备份
cd /workspace/infra/docker
docker-compose exec postgres pg_dump -U postgres fabric_erp | gzip > ~/fabric_erp_$(date +%Y%m%d).sql.gz
```

### 4.2 数据库恢复

```bash
# 恢复数据库
cd /workspace/infra/docker
gunzip < ~/fabric_erp_20260607.sql.gz | docker-compose exec -T postgres psql -U postgres fabric_erp
```

## 六、故障排查

### 6.1 常见问题

#### 6.1.1 服务无法启动

```bash
# 1. 检查端口占用
netstat -tlnp | grep -E ':(3000|5432|6379)'

# 2. 检查容器状态
docker-compose ps

# 3. 查看具体日志
docker-compose logs backend

# 4. 重启服务
docker-compose restart
```

#### 6.1.2 数据库连接失败

```bash
# 1. 检查数据库容器状态
docker-compose ps postgres

# 2. 检查连接
docker-compose exec postgres psql -U postgres -c "SELECT 1"

# 3. 检查网络
docker network ls

# 4. 重置数据库（仅限开发环境！）
# 注意：会清空所有数据
docker-compose down -v
docker-compose up -d
```

#### 6.1.3 Redis连接问题

```bash
# 1. 检查Redis状态
docker-compose ps redis

# 2. 连接测试
docker-compose exec redis redis-cli ping

# 3. 查看Redis信息
docker-compose exec redis redis-cli info
```

#### 6.1.4 内存溢出

```bash
# 1. 查看内存使用
docker stats

# 2. 增加容器内存限制
# 编辑docker-compose.yml
# services:
#   backend:
#     deploy:
#       resources:
#         limits:
#           memory: 2G
#         reservations:
#           memory: 1G

# 3. 重启服务
docker-compose up -d
```

```bash

# 2. 备份数据库（重要！）
```
