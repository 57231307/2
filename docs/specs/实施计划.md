## 1. 项目概述

### 1.1 项目目标
构建一个高性能、高准确性的纺织面料行业全功能ERP系统，覆盖55个核心业务模块，支持100万+数据量，响应时间<200ms。

### 1.2 技术栈
- **前端：** Angular 22+ + SignalForms + OnPush
- **后端：** NestJS 10+
- **数据库：** PostgreSQL 16+（分区表）
- **缓存/队列：** Redis 7+
