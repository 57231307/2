---

## 一、项目概述

### 1.1 项目背景
某纺织面料企业需要一套完整的ERP系统来管理企业的日常运营，包括采购、销售、库存、生产、财务等各个环节。该企业主要经营针织面料，具有颜色管理、花型管理、多单位换算等面料行业特殊需求。

### 1.2 项目目标
- 建立统一的企业资源管理平台
- 实现业务数据的准确性和一致性
- 优化业务流程，提高运营效率
- 支持决策分析，提供数据支撑
- 确保高准确性和高性能

### 1.3 项目范围
本项目为**全功能ERP系统**，覆盖企业运营的各个环节，特别针对针织面料行业的特点进行定制化开发。

## 二、功能需求

### 2.1 基础数据管理

#### 2.1.1 产品管理

**功能描述**
管理系统中的产品主数据，包括面料、坯布、染料、辅料等产品。

**功能要求**

| 功能点 | 优先级 | 描述 |
|--------|--------|------|
| 产品信息维护 | P0 | 新增、编辑、删除产品信息 |
| 产品分类 | P1 | 按类型分类管理产品 |
| 产品BOM | P1 | 产品物料清单管理 |
| 产品图片 | P1 | 产品图片上传和展示 |
| 产品价格 | P0 | 标准成本和销售价格管理 |
| 产品状态 | P0 | 启用/停用状态管理 |

**数据字段**
- 产品编码（系统生成，唯一）
- 产品名称（必填）
- 产品类型（枚举：面料/坯布/辅料/染料/其他）
- 规格参数（文本）
- 计量单位（默认：米）
- 颜色配方ID（关联）
- 花型ID（关联）
- 标准成本（decimal）
- 销售价格（decimal）
- 产品状态（枚举：启用/停用/停产）
- 备注（文本）

**业务规则**
- 产品编码自动生成，格式：PRD-YYYYMMDD-XXXX
- 产品名称不能重复
- 删除产品时检查是否有在途单据
