# 纺织面料ERP系统 - 用户操作手册

> 版本：V1.0
> 日期：2026年6月7日

## 一、欢迎使用

### 1.1 系统简介

**纺织面料ERP系统**是一套专为面料行业设计的企业级管理系统，涵盖：
- 产品、客户、供应商等基础数据管理
- 销售报价、订单、发货全流程
- 采购订单、入库、退货管理
- 库存批次、盘点、预警管理
- 生产工单、领料、生产入库
- 质量检验、颜色配方管理
- 财务应收、应付、成本核算

### 1.2 登录系统

#### 1.2.1 访问地址
- 开发环境：http://dev.fabric-erp.com
- 测试环境：http://test.fabric-erp.com
- 生产环境：http://fabric-erp.com

#### 1.2.2 登录步骤

1. 在浏览器中打开系统地址
2. 输入用户名和密码
3. 点击「登录」按钮
4. 首次登录建议修改初始密码

#### 1.2.3 忘记密码
如忘记密码，请联系系统管理员重置。

## 二、基础数据管理

### 2.1 产品管理

#### 2.1.1 新增产品

1. 点击左侧菜单「基础数据」→「产品管理」
2. 点击页面右上角「新增产品」按钮
3. 填写产品信息：
   - **产品编码**：自动生成，也可手动输入
   - **产品名称**：必填，输入产品名称
   - **产品类型**：选择面料/坯布/辅料/染料
   - **规格描述**：输入产品规格
   - **计量单位**：选择米/公斤/码
   - **颜色配方**：关联颜色标准（可选）
   - **花型**：关联花型（可选）
   - **标准成本**：输入标准成本
   - **销售价格**：输入销售价格
4. 点击「保存」按钮

#### 2.1.2 查询产品

1. 在产品列表页顶部筛选区输入查询条件
2. 点击「查询」按钮
3. 支持的查询条件：
   - 产品编码/名称
   - 产品类型
   - 状态（启用/停用）
   - 创建时间范围

#### 2.1.3 编辑产品

1. 在产品列表中找到要编辑的产品
2. 点击「编辑」按钮
3. 修改产品信息
4. 点击「保存」按钮

#### 2.1.4 停用产品

1. 在产品列表中找到要停用的产品
2. 点击「删除/停用」按钮
3. 确认操作
4. 注意：有库存或在途单据的产品不能停用

### 2.2 客户管理

#### 2.2.1 新增客户

1. 点击左侧菜单「基础数据」→「客户管理」
2. 点击「新增客户」
3. 填写客户信息：
   - 客户编码（自动生成）
   - 客户名称（必填）
   - 联系人/电话/邮箱
   - 地址信息
   - 信用额度
   - 付款天数
   - 负责销售员
4. 保存

#### 2.2.2 客户查询

支持按客户名称、类型、状态等条件查询

### 2.3 供应商管理

操作方式同客户管理，菜单路径「基础数据」→「供应商管理」

### 2.4 仓库管理

操作方式同上，菜单路径「基础数据」→「仓库管理」

## 三、销售管理

### 3.1 销售报价

#### 3.1.1 新建报价单

1. 点击左侧菜单「销售管理」→「销售报价」
2. 点击「新建报价」
3. 选择客户
4. 填写报价有效日期
5. 添加报价明细：
   - 选择产品
   - 输入数量
   - 选择颜色配方（如适用）
   - 选择花型（如适用）
   - 输入单价（可自动带出默认价）
6. 系统自动计算总价
7. 点击「保存」

#### 3.1.2 报价单转订单

1. 在报价单列表中找到已确认的报价
2. 点击「转订单」
3. 确认订单信息
4. 保存生成销售订单

### 3.2 销售订单

#### 3.2.1 新建订单

1. 点击「销售管理」→「销售订单」
2. 点击「新建订单」
3. 选择客户
4. 选择销售员
5. 填写订单日期和预计交货日期
6. 添加订单明细
7. 保存

#### 3.2.2 订单审批

1. 找到待审批的订单
2. 点击「查看详情」
3. 检查订单信息
4. 点击「审批」→「通过」或「驳回」

#### 3.2.3 订单状态说明

| 状态 | 说明 |
|------|------|
| 待审批 | 订单刚创建，等待审批 |
| 审批中 | 审批流程进行中 |
| 已审批 | 审批通过，可以发货 |
| 执行中 | 已开始发货但未完成 |
| 已完成 | 全部发货完成 |
| 已取消 | 订单取消 |

### 3.3 发货管理

#### 3.3.1 创建发货单

1. 点击「销售管理」→「发货管理」
2. 点击「新建发货单」
3. 选择对应的销售订单
4. 系统自动带出未发货的明细
5. 选择要发货的批次（面料行业必须指定批次）
6. 输入实际发货数量
7. 填写物流公司和运单号
8. 保存发货单

#### 3.3.2 批次选择说明

- **FIFO（先进先出）**：系统自动选择库龄最长的批次
- **指定批次**：手动选择要发货的批次
- **建议**：优先采用FIFO原则

### 3.4 销售退货

#### 3.4.1 退货操作

1. 点击「销售管理」→「销售退货」
2. 点击「新建退货单」
3. 选择原发货单
4. 选择退回的批次
5. 填写退货数量
6. 选择退货原因
7. 保存后提交质检

## 四、采购管理

### 4.1 采购订单

#### 4.1.1 新建采购订单

1. 点击「采购管理」→「采购订单」
2. 点击「新建订单」
3. 选择供应商
4. 填写采购明细
5. 保存

### 4.2 采购入库

#### 4.2.1 入库操作

1. 点击「采购管理」→「采购入库」
2. 点击「新建入库单」
3. 选择对应的采购订单
4. 系统自动带出待入库的明细
5. 填写实际入库数量
6. **重要**：系统自动生成批次号
7. 选择入库仓库
8. 提交质检

#### 4.2.2 批次生成说明

- 批次格式：BAT-YYYYMMDD-XXXX
- 同一供应商同一次入库的同一种产品可共用一个批次
- 批次信息包含：产品、生产日期/入库日期、供应商、颜色、花型等

## 五、库存管理（面料行业核心）

### 5.1 库存查询

#### 5.1.1 总库存查询

1. 点击「库存管理」→「库存查询」
2. 可按产品、仓库筛选
3. 查看每个产品在各仓库的库存总量

#### 5.1.2 批次库存查询

1. 点击「库存管理」→「批次库存」
2. 查看每个批次的详细库存信息
3. 可以看到：批次号、产品、仓库、数量、库龄等

### 5.2 库存盘点

#### 5.2.1 创建盘点计划

1. 点击「库存管理」→「库存盘点」
2. 点击「新建盘点」
3. 选择盘点类型（全面盘点/循环盘点）
4. 选择要盘点的仓库
5. 保存

#### 5.2.2 执行盘点

1. 在盘点计划详情页
2. 打印盘点单
3. 实物盘点后填写实际数量
4. 在系统中录入盘点结果
5. 提交审批

#### 5.2.3 差异处理

- 盘点差异需经审批后才能调整库存
- 生成盘点盈亏单

### 5.3 库存预警

#### 5.3.1 查看预警

1. 点击「库存管理」→「库存预警」
2. 查看：
   - 低于安全库存的产品
   - 接近或超过最高库存的产品
   - 即将到期的批次（如适用）
3. 及时处理

## 六、生产管理

### 6.1 生产工单

#### 6.1.1 新建工单

1. 点击「生产管理」→「生产工单」
2. 点击「新建工单」
3. 选择要生产的产品
4. 输入生产数量
5. 选择工艺路线
6. 填写计划日期
7. 保存并下达

### 6.2 生产领料

#### 6.2.1 创建领料单

1. 点击「生产管理」→「生产领料」
2. 关联生产工单
3. 系统自动带出所需物料
4. 填写实领数量
5. 确认后物料从库存扣除

### 6.3 生产入库

#### 6.3.1 生产完工入库

1. 工单完成后点击「生产入库」
2. 填写合格数量和不合格数量
3. 系统自动生成新批次
4. 完工产品入成品仓库

## 七、质量管理

### 7.1 来料质检

#### 7.1.1 执行质检

1. 点击「质量管理」→「来料质检」
2. 找到待质检的入库单
3. 点击「执行质检」
4. 按质检标准逐项检验
5. 填写检验结果
6. 判定合格/不合格
7. 合格产品入库，不合格产品退货处理

### 7.2 色差检测（面料行业特色）

#### 7.2.1 色差检测操作

1. 在质检页面找到「色差检测」项
2. 使用色差仪测量样品
3. 输入LAB值
4. 系统自动计算ΔE值
5. 判断是否在允差范围内（通常ΔE≤1.0）

### 7.3 出货质检

订单发货前执行，操作方式同来料质检

## 八、颜色配方管理（面料行业特色）

### 8.1 颜色标准管理

#### 8.1.1 新建颜色标准

1. 点击「基础数据」→「颜色配方」
2. 点击「新建颜色标准」
3. 填写颜色信息：
   - 颜色名称
   - 色号
   - LAB值（L=明度，a=红绿，b=黄蓝）
4. 上传颜色样品图片
5. 保存

### 8.2 染料配方管理

#### 8.2.1 新建染料配方

1. 在颜色标准详情页点击「新建配方」
2. 添加染料明细：
   - 选择染料
   - 输入用量百分比
   - 输入染料单价
3. 系统自动计算配方成本
4. 保存配方

#### 8.2.2 配方计算

1. 点击「计算用量」
2. 输入目标生产数量
3. 系统自动计算每种染料的实际用量
4. 可打印染料投料单

## 十一、常见问题

### 11.1 基础数据问题

**Q：产品编码能修改吗？**
A：建议不要修改，如果必须修改请联系管理员，修改前确保没有关联单据。

**Q：客户信用额度不足怎么办？**
A：联系财务调整信用额度，或先收部分货款。

### 11.2 库存问题

**Q：找不到批次怎么办？**
A：检查批次是否已被冻结或关闭，或查询条件是否正确。

**Q：盘点有差异怎么处理？**
A：先确认实物是否正确，差异较小的可以按正常流程调整，差异较大的需要财务审核。

### 11.3 系统问题

**Q：系统登录不进去？**
A：检查用户名密码是否正确，确认网络连接，或联系管理员。

**Q：页面加载很慢？**
A：尝试刷新页面，如持续慢请联系IT支持。
